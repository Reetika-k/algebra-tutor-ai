9. Limitations

  • Every AI result here comes from the local qwen2:7b model; the Claude provider path has not been exercised live. Results are per provider and never mixed.
  • One run per version: scenario outcomes vary between runs with a sampled model (reply length, off-topic drift), so single-run pass rates are indicative, not precise.
  • Scenario checks are automated assertions on structure and content; the quality of an explanation beyond those checks is a human judgement (see the demo script).
  • Latencies are local-laptop figures for a 7B model and say nothing about the hosted Claude path.

Reproduce

npm test → npm run test:tap (records the unit run) → npm run test:scenarios (needs a model; writes tests/results/) → npm run dashboard. This file embeds its figures and screenshots.
